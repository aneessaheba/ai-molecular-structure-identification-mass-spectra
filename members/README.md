# Member Workspaces

Each member has their own folder named after their GitHub username. Teammates who are not listed yet: create `members/<your-github-username>/` and copy the README template from another member folder.

Inside your folder:
```
members/<username>/
├── README.md        # Your models, results, Kaggle submissions
├── 01_<model>.ipynb
├── 02_<model>.ipynb
└── 03_<model>.ipynb  (optional)
```
Move reusable code into `src/` so others can use it.
